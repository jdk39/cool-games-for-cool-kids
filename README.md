# Cool Games for Cool Kids

A gaming platform (SaaS) for discovering upcoming games, tracking a backlog of games to play, getting personalized recommendations, and adding friends.

## Features
- Game search & recommendations (powered by the IGDB API)
- Friend system
- Backlog of games to play

## Architecture
3-tier deployment on AWS:
- **Presentation** — static frontend
- **Application** — API servers (auth, friend system, recommendations)
- **Data** — RDS (MySQL)
